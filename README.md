## Sobre o projeto

O portfólio reúne informações sobre minha trajetória, projetos desenvolvidos e planejados, além das tecnologias que fazem parte dos meus estudos.

O projeto foi desenvolvido com foco em uma interface moderna, responsiva e organizada.

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Vite
- React Router

## Funcionalidades

- Navegação entre diferentes páginas
- Página de apresentação
- Seção sobre mim
- Apresentação de projetos
- Página de tecnologias
- Página de contato
- Modo claro e escuro
- Preferência de tema salva no navegador
